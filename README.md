# XAUUSD ট্রেডিং সিস্টেম — Renko-50 + EMA 9/12 ক্রসওভার + ১ মাসের ব্যাকটেস্ট

গোল্ড (XAUUSD) এর জন্য **Renko-50 চার্টে শুধু EMA 9/12 ক্রসওভার** —
ক্যান্ডেলস্টিক নয়, কোনো বাড়তি লজিকও নয়। Python ব্যাকটেস্ট + MT5 EA সহ।

## ফাইল স্ট্রাকচার

```
├── src/
│   ├── indicators.py   # EMA
│   ├── renko.py        # M15 → Renko-50 ব্রিক বিল্ডার
│   ├── strategy.py     # শুধু EMA 9/12 ক্রস সিগন্যাল
│   └── backtest.py     # রিভার্স-এক্সিট ব্যাকটেস্ট ইঞ্জিন + মেট্রিক্স
├── data/
│   ├── xauusd_m15_slice.csv       # সোর্স M15 ডেটা
│   ├── xauusd_m15_1month.csv      # ১ মাসের M15 ডেটা
│   └── xauusd_renko50_bricks.csv  # বানানো Renko ব্রিক
├── results/
│   ├── backtest_report.md  # ফুল রিপোর্ট
│   ├── trades.csv          # প্রতিটা ট্রেডের হিসাব
│   ├── equity_curve.csv    # ইকুইটি কার্ভ ডেটা
│   └── backtest_chart.png  # Renko + ট্রেড + ইকুইটি + ড্র-ডাউন চার্ট
├── mql5/
│   └── XAUUSD_EmaCross.mq5  # MT5 Expert Advisor
└── run_backtest.py  # ব্যাকটেস্ট চালানোর স্ক্রিপ্ট (BRICK = 0.50 বদলানো যায়)
```

## ব্যাকটেস্ট আবার চালানো

```bash
pip install -r requirements.txt
python3 run_backtest.py
```

ব্রিক সাইজ বদলাতে চাইলে `run_backtest.py` এর `BRICK = 0.50` লাইন বদলান।

## MT5 এ ব্যবহার (Renko অফলাইন চার্ট)

MT5-এ সরাসরি Renko নেই, তাই:
1. একটা **Renko generator EA** দিয়ে XAUUSD M15 থেকে Renko-50 অফলাইন চার্ট বানান।
2. `mql5/XAUUSD_EmaCross.mq5` → `MQL5/Experts/` ফোল্ডারে → Compile।
3. ওই **অফলাইন Renko চার্টে** EA attach করুন (EA যেকোনো চার্টে কাজ করে), Algo Trading ON।
4. প্রথমে **Strategy Tester + ডেমো** তে চালান।
