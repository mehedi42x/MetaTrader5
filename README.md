# XAUUSD — EMA 9/12 Crossover on **M3 Candles**

গোল্ড (XAUUSD) এর জন্য সহজ সিস্টেম: **নরমাল ক্যান্ডেল চার্ট, ৩ মিনিট টাইমফ্রেম,
EMA 9 / EMA 12 ক্রসওভার**। রেনকো সব বাদ।

## সিস্টেম রুলস (একদম সহজ)

| অংশ | রুল |
|---|---|
| চার্ট | **নরমাল ক্যান্ডেল, M3** (আসল XAUUSD M1 থেকে বানানো: tiumbj/M1_XAUUSD) |
| BUY | EMA9 **উপরে** ক্রস করলে |
| SELL | EMA9 **নিচে** ক্রস করলে |
| EXIT | উল্টো ক্রস = ক্লোজ + রিভার্স (সবসময় মার্কেটে) |
| লট | ফিক্সড **0.10** |
| কস্ট | স্প্রেড $0.35/oz + স্লিপেজ $0.10/oz (= **$4.50 প্রতি ট্রেড**) |
| বাকি সব | ❌ কোনো RSI / SL-TP / সেশন ফিল্টার / রেনকো নেই |

M15-এ ৯-১২ ক্রস আসলে পজিটিভ, কিন্তু M3/M1-এ একই সিস্টেম ধ্বংস হয়ে যায়।

│   └── backtest.py     # ব্যাকটেস্ট ইঞ্জিন (রিভার্স এক্সিট)

│   ├── backtest_chart.png    # M3 ব্যাকটেস্ট চার্ট

│   ├── backtest_report.md    # ফুল রিপোর্ট
│   ├── trades.csv, equity_curve.csv

## MT5 এ ব্যবহার

1. XAUUSD-এর **নরমাল M3 ক্যান্ডেল চার্ট** খুলুন।
2. `mql5/XAUUSD_EmaCross.mq5` → `MQL5/Experts/` → Compile → চার্টে attach।
3. প্রথমে **ডেমোতে** চালান — উপরের ব্যাকটেস্টে এই সিস্টেম ২ মাসে -৭৫% করেছে।
