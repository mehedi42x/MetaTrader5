# XAUUSD ট্রেডিং সিস্টেম — EMA 9/12 ক্রসওভার (M15) + ১ মাসের ব্যাকটেস্ট

গোল্ড (XAUUSD) M15 ক্যান্ডেলে **শুধু EMA 9/12 ক্রসওভার** — আর কোনো লজিক নেই।
Python ব্যাকটেস্ট + MT5 Expert Advisor (.mq5) সহ।

## সিস্টেম রুলস (শুধু ক্রসওভার)

| অংশ | রুল |
|---|---|
| BUY | EMA9 নিচ থেকে উপরে EMA12 কে ক্রস করলে |
| SELL | EMA9 উপর থেকে নিচে EMA12 কে ক্রস করলে |
| EXIT | উল্টো ক্রসে পজিশন ক্লোজ + রিভার্স (সবসময় মার্কেটে) |
| লট | ফিক্সড **0.10** |
| বাকি সব | ❌ কোনো RSI / সেশন ফিল্টার / SL-TP নেই |

সিগন্যাল কনফার্ম হয় ক্যান্ডেল **ক্লোজে**, এন্ট্রি **পরের ক্যান্ডেলের ওপেনে**।

## ১ মাসের ব্যাকটেস্ট রেজাল্ট

- **পিরিয়ড:** 2022-02-02 → 2022-03-04 (30 দিন, 2015টা M15 ক্যান্ডেল)
- **ডেটা:** XAUUSD M15, Dukascopy-সোর্সড হিস্টোরিক্যাল ডেটা
- **ব্যালেন্স:** $10,000 | ফিক্সড 0.10 লট | স্প্রেড $0.35/oz + স্লিপেজ $0.10/oz সহ

| মেট্রিক | রেজাল্ট |
|---|---|
| মোট ট্রেড | **109** (Buy 55 / Sell 54) |
| উইন রেট | **29.4%** (32 win / 77 loss) |
| নেট প্রফিট | **+$777.20 (+7.77%)** → ব্যালেন্স $10,777.20 |
| প্রফিট ফ্যাক্টর | **1.30** |
| প্রতি ট্রেডে গড় | **+$7.13** |
| সর্বোচ্চ ড্র-ডাউন | **-6.64%** |
| Sharpe (daily) | 1.61 |

> ⚠️ **সৎ কথা:** ফাস্ট EMA ক্রসে প্রচুর whipsaw হয় (১০৯ ট্রেড, মাত্র ২৯% উইন)।
> পাশের মাসে: Dec-2021: **-5.7%**, Jan-2022: **-3.0%**, Feb-2022: **+7.8%**
> (Feb-তে বড় একটা ট্রেন্ড ছিল বলে প্রফিট)। এই সিস্টেম শুধু স্ট্রং ট্রেন্ডে টিকে —
> রিয়েল টাকার আগে ডেমোতে চালান।

## ফাইল স্ট্রাকচার

```
├── src/
│   ├── indicators.py   # EMA
│   ├── strategy.py     # শুধু EMA 9/12 ক্রস সিগন্যাল
│   └── backtest.py     # রিভার্স-এক্সিট ব্যাকটেস্ট ইঞ্জিন + মেট্রিক্স
├── data/
│   ├── xauusd_m15_1month.csv  # টেস্ট পিরিয়ডের ১ মাসের ডেটা
│   └── xauusd_m15_slice.csv   # warmup সহ স্লাইস
├── results/
│   ├── backtest_report.md  # ফুল রিপোর্ট
│   ├── trades.csv          # প্রতিটা ট্রেডের হিসাব
│   ├── equity_curve.csv    # ইকুইটি কার্ভ ডেটা
│   └── backtest_chart.png  # প্রাইস + ট্রেড + ইকুইটি + ড্র-ডাউন চার্ট
├── mql5/
│   └── XAUUSD_EmaCross.mq5  # MT5 Expert Advisor (একই সিস্টেম)
└── run_backtest.py  # ব্যাকটেস্ট চালানোর স্ক্রিপ্ট
```

## ব্যাকটেস্ট আবার চালানো

```bash
pip install -r requirements.txt
python3 run_backtest.py
```

## MT5 এ EA ব্যবহার

1. `mql5/XAUUSD_EmaCross.mq5` → MT5 `MQL5/Experts/` ফোল্ডারে → Compile।
2. XAUUSD **M15** চার্টে attach করুন, Algo Trading ON।
3. প্রথমে **Strategy Tester + ডেমো** তে চালান।
