# XAUUSD ট্রেডিং স্ট্র্যাটেজি — Gold Trend-Momentum v1 (M15) + ১ মাসের ব্যাকটেস্ট

গোল্ড (XAUUSD) এর জন্য একটা সিম্পল ট্রেন্ড-ফলোইং স্ট্র্যাটেজি, Python ব্যাকটেস্ট ইঞ্জিন,
১ মাসের রিয়েল M15 ডেটার রেজাল্ট, আর MetaTrader 5 এর জন্য রেডি Expert Advisor (.mq5) — সব একসাথে।

## স্ট্র্যাটেজি রুলস (XAUUSD, M15)

| অংশ | রুল |
|---|---|
| ট্রেন্ড ফিল্টার | `Close > EMA20 > EMA50` → শুধু BUY; `Close < EMA20 < EMA50` → শুধু SELL |
| এন্ট্রি ট্রিগার | RSI(14) ট্রেন্ডের দিকে **50 লাইন ক্রস** করলে (মোমেন্টাম কনফার্মেশন) |
| সেশন ফিল্টার | শুধু **07:00–21:00 GMT** (লন্ডন + নিউ ইয়র্ক) এ এন্ট্রি |
| স্টপ-লস / টেক-প্রফিট | SL = **2 × ATR(14)**, TP = **4 × ATR(14)** → রিস্ক:রিওয়ার্ড **1:2** |
| রিস্ক ম্যানেজমেন্ট | প্রতি ট্রেডে **১% রিস্ক**, একবারে **১টা পজিশন**, কোনো মার্টিংগেল/গ্রিড নেই |

সিগন্যাল কনফার্ম হয় ক্যান্ডেল **ক্লোজে**, এন্ট্রি হয় **পরের ক্যান্ডেলের ওপেনে**
(অর্থাৎ কোনো lookahead bias নেই)।

## ১ মাসের ব্যাকটেস্ট রেজাল্ট

- **পিরিয়ড:** 2022-02-02 → 2022-03-04 (30 দিন, 2015টা M15 ক্যান্ডেল)
- **ডেটা:** XAUUSD M15, Dukascopy-সোর্সড হিস্টোরিক্যাল ডেটা (ejtraderLabs/historical-data)
- **ব্যালেন্স:** $10,000 | স্প্রেড $0.35/oz + স্লিপেজ $0.10/oz সহ

| মেট্রিক | রেজাল্ট |
|---|---|
| মোট ট্রেড | **25** (Buy 16 / Sell 9) |
| উইন রেট | **52%** (13 win / 12 loss) |
| নেট প্রফিট | **+$1,121.62 (+11.22%)** → ব্যালেন্স $11,121.62 |
| প্রফিট ফ্যাক্টর | **1.77** |
| প্রতি ট্রেডে গড় (expectancy) | **+$44.86** |

| Sharpe (daily) | 4.69 |

> ১ মাস ছোট স্যাম্পল। রিয়েল টাকার আগে **ডেমোতে ফরওয়ার্ড-টেস্ট** করুন, রিস্ক ≤1% রাখুন।

## ফাইল স্ট্রাকচার

```
├── src/
│   ├── indicators.py   # EMA, RSI (Wilder), ATR
│   ├── strategy.py     # সিগন্যাল লজিক (PARAMS এখানে বদলান)
│   └── backtest.py     # বার-বাই-বার ব্যাকটেস্ট ইঞ্জিন + মেট্রিক্স
├── data/
│   ├── xauusd_m15_1month.csv  # টেস্ট পিরিয়ডের ১ মাসের ডেটা
│   └── xauusd_m15_slice.csv   # warmup সহ স্লাইস (ইন্ডিকেটরের জন্য)
├── results/
│   ├── backtest_report.md  # ফুল রিপোর্ট
│   ├── trades.csv          # প্রতিটা ট্রেডের হিসাব
│   ├── equity_curve.csv    # ইকুইটি কার্ভ ডেটা
│   └── backtest_chart.png  # প্রাইস + ট্রেড + ইকুইটি + ড্র-ডাউন চার্ট
├── mql5/
│   └── XAUUSD_GoldTrendMomentum.mq5  # MT5 Expert Advisor (একই স্ট্র্যাটেজি)
└── run_backtest.py  # ব্যাকটেস্ট চালানোর স্ক্রিপ্ট
```

## ব্যাকটেস্ট আবার চালানো

```bash
pip install -r requirements.txt
python3 run_backtest.py
```

## MT5 এ EA ব্যবহার

1. `mql5/XAUUSD_GoldTrendMomentum.mq5` ফাইলটা কপি করে MT5 এর
   `MQL5/Experts/` ফোল্ডারে রাখুন → Compile (F4 → MetaEditor)।
2. XAUUSD **M15** চার্টে attach করুন, Algo Trading ON করুন।
3. ⏰ সেশন টাইম **সার্ভার টাইমে** — ব্যাকটেস্ট 07–21 GMT।
   ব্রোকার GMT+2 হলে input এ `09–23` সেট করুন।
4. প্রথমে **Strategy Tester + ডেমো** তে চালান।
