## 🔴 বাগ ১ — Body Overlap ফিল্টার প্রায় সব ট্রেড ব্লক করে

```csharp
bool overlap = bodyLow <= prevBodyHigh && bodyHigh >= prevBodyLow;
```

কন্টিনিউয়াস ফিডে বার i এর open = বার i−1 এর close, তাই দুই বডি **সংজ্ঞা অনুযায়ীই** অন্তত এক বিন্দুতে মেলে।

| ডেটাসেট | 5M open == prev close | overlap=True |
|---|---|---|
| 2021-25 (HistData) | 25.0% | **80.1%** |
| 2026 (gapless) | 100.0% | **99.97%** |

**ফল:** ২০২৬ এ ফিল্টার চালু রাখলে **০টি ট্রেড**। ২০২১-২৫ এ ৬৫,৭২৭ → ৯,৩২৩।

**সমাধান:** স্পর্শ নয়, প্রকৃত ওভারল্যাপ শতাংশ মাপুন —
```csharp
double inter = Math.Min(bodyHigh, prevBodyHigh) - Math.Max(bodyLow, prevBodyLow);
double minBody = Math.Min(bodyHigh - bodyLow, prevBodyHigh - prevBodyLow);
bool overlap = minBody > 0 && (inter / minBody) >= OverlapMinRatio;  // যেমন 0.5
```
