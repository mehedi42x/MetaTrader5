## ১) S7 আর S1 — এর মানে কী? (আসল ব্যাখ্যা)

দুটোই **SMC (Smart Money Concepts)** লজিক থেকে বানানো সিস্টেম। "S7" আর "S1" হলো
আমাদের এই প্রজেক্টে দেওয়া **সিস্টেম নাম্বার** — আমি পরপর অনেকগুলো ভ্যারিয়েন্ট টেস্ট
করেছিলাম, নামগুলো ছিল S1, S2, S3, S4, S5, S6, S7। তার মধ্যে **শুধু S7 আর S1 প্রফিটেবল**,
তাই এই দুটোকে একসাথে করা হলো।

### 🟦 S7 = Order Block Retest (চার্ট টাইমফ্রেম, M1)

> **মূল কথা:** স্ট্রাকচার ব্রেক হওয়ার পর যে **অর্ডার ব্লক** থেকে ব্রেকটা এসেছে, দাম
> যখন আবার সেখানে ফিরে আসে — তখন ট্রেড।

ধাপে ধাপে:

1. **Swing Structure (length 50)** — প্রতি ৫০ ক্যান্ডেলের মধ্যে সবচেয়ে উঁচু হাই = swing
   high, সবচেয়ে নিচু লো = swing low। এই লেভেলগুলোই "স্ট্রাকচার"।
2. **BOS / CHoCH ডিটেকশন**
   - ক্লোজ swing high-এর **উপরে** গেল → **bullish break** (BOS = trend continue, CHoCH = trend flip)
   - ক্লোজ swing low-এর **নিচে** গেল → **bearish break**
3. **Order Block সেভ** — যে ব্রেকটা হলো, তার পিছনে যে ক্যান্ডেল থেকে মুভমেন্টটা শুরু
   হয়েছিল সেটাই **order block** (বড় ATR(200)-এর ২ গুণ রেঞ্জের ক্যান্ডেল হলে LuxAlgo
   "parsed" high/low ব্যবহার করে)। সেটার **উপরের প্রান্ত = entry level**, **নিচের প্রান্ত = stop level**।
4. **Entry** — দাম আবার ব্লকে ঢুকলে (low ≤ block top) **limit অর্ডার** ফিল হয় ব্লকের উপরের প্রান্তে
   (গ্যাপ হলে open-এ)।
5. **Exit (ক্লোজ সিগন্যাল)**
   - ⛔ **Block failed** — ক্লোজ ব্লকের নিচের প্রান্তের নিচে গেলে (এটাই কার্যত স্টপলস)
   - ✖ **Structure flip** — স্ট্রাকচার উল্টো দিকে ব্রেক করলে

**২০২২ রেজাল্ট:** **+$702.06**, 1,337 ট্রেড, উইন **21.6%**, **PF 1.67**, Max DD **-$40**
→ কম উইন রেট, কিন্তু যেগুলো জেতে সেগুলো অনেক বড় (risk/reward দারুণ)।

### 🟥 S1 = Swing Structure Flip (উপরের টাইমফ্রেম, M5)

> **মূল কথা:** স্ট্রাকচার যেদিকে ব্রেক করবে, ট্রেড সেদিকে। বিপরীত ব্রেক হলে পজিশন উল্টে যায়।
> সবসময় মার্কেটে থাকে (always in market)।

1. **M5 চার্টে** swing structure (length 50) বের করা হয়।
2. **Bullish break (BOS/CHoCH)** → **BUY**, আর আগের শর্ট থাকলে বন্ধ।
3. **Bearish break** → **SELL**, আর আগের লং থাকলে বন্ধ।
4. অর্থাৎ প্রতি ব্রেক = একটা নতুন দিক, পজিশন সবসময় একটা।

**২০২২ রেজাল্ট:** **+$214.96**, 278 ট্রেড, উইন **38.1%**, **PF 1.15**, Max DD **-$231**

### কেন দুটো একসাথে?

| | S7 | S1 |
|---|---|---|
| টাইমফ্রেম | M1 (চার্ট) | M5 (HTF) |
| লজিক | ব্রেকের পর **পুলব্যাক ধরে** ফেলো | ব্রেকের **সাথে সাথে** ফেলো |
| ট্রেড সংখ্যা | 1,337 | 278 |
| ২০২২ P/L | +$702 | +$215 |

দুই সিস্টেমের **দৈনিক P/L কোরিলেশন মাত্র 0.14** — অর্থাৎ তাদের খারাপ দিন একসাথে পড়ে না।
তাই একসাথে চালালে: **+$917.02**, **PF 1.37**, Max DD **-$167**, ১২ মাসের ৭ মাস পজিটিভ।

### 📖 ছোট শব্দকোষ
- **BOS (Break of Structure)** — ট্রেন্ডের দিকেই আগের swing লেভেল ভাঙা (ধারাবাহিকতা)
- **CHoCH (Change of Character)** — উল্টো দিকে ব্রেক, ট্রেন্ড বদলের ইঙ্গিত
- **Order Block** — বড় মুভমেন্টের ঠিক আগের ক্যান্ডেল; ইনস্টিটিউশনাল অর্ডারের জায়গা ধরা হয়
- **Swing Structure** — ৫০ ক্যান্ডেলের fractal high/low দিয়ে বানানো মূল স্ট্রাকচার

## ২) TradingView-এ কীভাবে বসাবেন

1. TradingView খুলুন → **XAUUSD** চার্ট → টাইমফ্রেম **M1** (১ মিনিট) দিন।
   *(S7 M1-এ টেস্ট করা; অন্য TF-এ নাম্বার বদলে যাবে)*
2. নিচে **Pine Editor** খুলুন → `pine/s7_s1_combined.pine` ফাইলের পুরো কোড কপি করে পেস্ট করুন
3. **Save** → নাম দিন (যেমন "S7+S1 Combined") → **Add to chart**
4. চার্টে এখন দেখবেন:
   - `▲ BUY S7 1801.25 ✦ SL 1798.40` — S7 এন্ট্রি
   - `▼ SELL S1 (CHoCH 5)` — S1 এন্ট্রি
   - `⛔ SL S7`, `✔ TP S1`, `✖ CLOSE S7` — ট্রেড কোথায় বন্ধ হলো
   - ডান কোণে **status panel** — দুই সিস্টেমের পজিশন, entry, SL, TP, লাইভ P/L
   - order block-গুলো নীল/লাল বক্সে আঁকা
5. **Settings (⚙)** খুলে `Preset` বেছে নিন (নিচে ব্যাখ্যা), দরকার হলে হাতেও বদলান।

### 🔔 অ্যালার্ট সেট করা
চার্টে ক্লিক → **Add alert** → Condition = "S7 + S1 Combined" → নিচের যেকোনো একটা বেছে নিন:
`S7 BUY`, `S7 SELL`, `S1 BUY`, `S1 SELL`, `S7 SL`, `S7 TP`, `S7 CLOSE`, `S1 SL`, `S1 TP`,
`S1 CLOSE`, `ANY entry`। মেসেজে লট/এন্ট্রি প্রাইস/এসএল/টিপি-সহ আসবে।

> ⚠️ `S1` সিগন্যাল M5 ক্যান্ডেল **ক্লোজ হওয়ার পরে** আসে (লুক-অ্যাহেড নেই, রিপেইন্ট করে না)।
> `S7` এন্ট্রি intrabar (লিমিট অর্ডার ফিল) — তাই ওই অ্যালার্টটা per-bar ফ্রিকোয়েন্সিতে।
